# FairWay Manufacturing Website

Source for the public facing FairWay Manufacturing website.

FairWay Manufacturing builds custom wiring harnesses in Arab, Alabama, with work spanning street sweeper and industrial equipment, automotive applications, marine/recreational equipment, and custom OEM needs.

## What this repository contains

- Static HTML website
- CSS styling
- GitHub Pages compatible deployment files

The site is intentionally lightweight so it can be hosted as a simple static site without a server side application.

## Customer workflow

The website is informational rather than an e commerce storefront.

Customers request a custom quote based on the harness or application they need.

## Technical note

This repository is a small business website, not part of my cloud/network engineering portfolio. I built and maintain it as a practical web project for a real business.
